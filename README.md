# שוקולד בתבנית

אפליקציה בעברית RTL המלווה ניסוי בהתכה והתמצקות של שוקולד.

## פיתוח

Node.js 22 ומעלה. התקנה: `npm ci`; הרצה: `npm run dev`; בנייה: `npm run build`.

## פרסום ב־Vercel

ייבוא המאגר כפרויקט Next.js. יש ליצור Vercel Blob פרטי ולחבר אותו לפרויקט, לסביבות Production ו־Preview. החיבור מספק `BLOB_READ_WRITE_TOKEN` בצד השרת בלבד. אין לשתף או לשמור את ערכו במאגר.

סרטונים (עד 30MB) מועלים ישירות מהדפדפן ל־Blob כדי להימנע ממגבלת גוף הבקשה של Functions. דוחות נשמרים כ־JSON פרטי. אישורי הגשה נפתחים באמצעות מזהה UUID אקראי שקבוצת התלמידים מעבירה למורה. מרחב המורה מכיל הנחיות ופתיחת קישור הגשה; אין בו אימות תפקיד נפרד או רשימה ציבורית של הגשות.

הנתונים שנשמרו בגרסת Sites אינם מועתקים אוטומטית. קישורי ההגשות הישנים ממשיכים להשתמש בכתובת המקורית.
